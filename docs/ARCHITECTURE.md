## 技术栈总览

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | React 19 + TypeScript | Vite 构建，Tailwind CSS 样式 |
| 国际化 | react-i18next | 中英文双语，~250 翻译键覆盖 35+ 组件 |
| 后端框架 | FastAPI (Python) | SSE 流式响应，lifespan 启动钩子 |
| 数据库 | SQLite (aiosqlite) | 本地持久化，每用户数据隔离 |
| 认证 | GitHub OAuth + Session | auth_middleware 拦截校验 |
| LLM 引擎 | OpenAI 兼容协议 | 7 个 Provider 可插拔：OpenAI / DeepSeek / 豆包 / Ollama / 自定义 |
| 代码分析 | tree-sitter | AST 级语法解析，10 种语言支持 |
| 邮件 | aiosmtplib | SMTP 域名智能匹配，无需手动配 host/port |
| 安全 | Fernet AES + bcrypt | API Key 加密存储 + 密码哈希 |
| 测试 | pytest | 50+ 测试用例，覆盖核心链路 |

## 核心模块详解

### 后端路由 (`backend/routers/`)

| 路由 | 端点 | 职责 |
|------|------|------|
| health | GET /api/health | 健康检查 |
| auth | GET /api/auth/login | GitHub OAuth 登录跳转 |
| auth | GET /api/auth/callback | OAuth 回调处理 |
| auth | GET /api/auth/me | 当前用户信息 |
| repos | GET/POST /api/repos | 仓库列表 + 手动添加 |
| monitor | GET/POST/DELETE /api/monitor | 监控仓库管理 |
| review | GET /api/review | SSE 流式评审 |
| history | GET/DELETE /api/history | 评审历史 CRUD |
| providers | GET/POST/PUT/DELETE /api/providers | LLM 提供商管理 |
| settings | GET/PUT /api/settings | 用户配置读写 |
| scheduler | GET/POST /api/scheduler/* | 调度器状态 + 启停 |

### 前端页面 (`frontend/src/pages/`)

| 页面 | 路由 | 功能 |
|------|------|------|
| LoginPage | / | GitHub OAuth 登录 |
| DashboardPage | /dashboard | 仓库列表 + 监控面板 + 最近评审 |
| PRInputPage | /review | 输入 PR URL + 模型 + 维度选择 |
| ReviewReportPage | /report/:id | 评审报告完整展示 |
| HistoryPage | /history | 搜索 + 日期筛选 + 趋势表 |
| SettingsPage | /settings | Provider 管理 + 通知 + 分片策略 + 语言 |
| SharePage | /share/:id | 匿名分享评审报告 |
